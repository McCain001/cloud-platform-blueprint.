# Security Policy

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's [private vulnerability reporting](../../security/advisories/new) for this repository, or email the maintainer.

Include:

- A description of the issue and its impact
- Steps to reproduce
- Affected files / components

You will receive an acknowledgement within 72 hours.

## Scope

This is a reference/learning repository. Do not deploy it to production without reviewing [`docs/security.md`](docs/security.md), in particular the CI role permissions.
